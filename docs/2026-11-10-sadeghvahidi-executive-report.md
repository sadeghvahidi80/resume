## ۵. قراردادها و محدودیت‌های مقدس (تخطی‌ناپذیر)

1. **فقط fa/en** برای ویرایش محتوای ریشه؛ ۷ زبان دیگر رزومه دست نمی‌خورند مگر در تسک ترجمه صریح.
2. **`/resume.html` هرگز ریدایرکت نمی‌شود** (رفتار انتخاب‌گر زبان حفظ).
3. **`magazine.html` تا انتشار اولین مقاله `noindex,follow` می‌ماند** و در sitemap نیست.
4. **قرارداد صداقت (spec §۱۰):** جعل ممنوع؛ جای‌خالی فقط با نشان‌های مصوب `[در انتظار آمار]`/`[در انتظار مدرک]`/`[در انتظار تاریخ]`؛ هیچ عددی بدون منبع واقعی زنده نمی‌رود.

6. **هر تسک:** چک ساختاری → کامیت conventional → push → Pages build (`gh api …/builds/latest --jq ".status"` پس از ≥۶۰ ثانیه) → راستی‌آزمایی زنده → چک موبایل 360/390 بدون هورفلو.
