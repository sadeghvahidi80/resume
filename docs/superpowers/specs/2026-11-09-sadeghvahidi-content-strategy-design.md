## ۷. مسیر تبدیل و فرم همکاری (ب۳)

**CTAها:** دکمه اصلی `[درخواست بررسی پروژه]` در Hero خانه + انتهای خانه + صفحه خدمات + انتهای رزومه. دکمه‌های فرعی: `[پروژه‌های شاخص]` و `[مشاهده رزومه]`.

**صفحه خدمات (services.html) — جدید:**
- ۴ خدمت با ساختار: توضیح راهکار + «چه چیزی تحویل می‌گیرید» + حالت همکاری (پروژه‌ای/مشاوره‌ای/استخدامی)
- CTA پایانی ← فرم تماس

**صفحه تماس (بازطراحی):**
- **دو کانال اصلی:** تلگرام + ایمیل (برجسته، کنار هم)
- کانال‌های جایگزین یک ردیف فرعی: لینکدین، اینستاگرام، دو شماره تلفن (با توضیح کوتاه نقش)
- **فرم درخواست همکاری (فیلدها):** نام • ایمیل یا آیدی تلگرام (برای پاسخ) • نوع درخواست (مدیریت پروژه / سیستم‌سازی / پژوهش بازار / محتوا / استخدام) • پیام
- **مسیر فرم:** فرم → `POST` به Cloudflare Worker (توکن مخفی) → `Telegram Bot sendMessage` به chat_id شما. اگر ارسال شکست خورد، گزینه `mailto:` به‌عنوان fallback ظاهر می‌شود (متن پیام حفظ می‌شود).
- **ضداسپم:** فیلد honeypot + محدودیت ساده زمانی (حداقل ۳ ثانیه بین باز کردن صفحه و ارسال).

## ۸. سئوی ساختاری (ب۴)

| صفحه | title (نمونه) | H1 | schema |
|---|---|---|---|
| خانه | «صادق وحیدی — مدیر پروژه دیجیتال و طراح فنی سیستم‌های عملیاتی» | «صادق وحیدی» | WebSite + Person |
| درباره من | «درباره صادق وحیدی — روایت حرفه‌ای» | «درباره من» | Person |
| پروژه‌ها | «پروژه‌ها و مطالعات موردی — صادق وحیدی» | «پروژه‌ها و مطالعات موردی» | BreadcrumbList |
| خدمات و همکاری | «خدمات مدیریت پروژه و سیستم‌سازی — صادق وحیدی» | «خدمات و همکاری» | BreadcrumbList + Service (کم‌حجم) |
| تماس | حفظ | «بیایید گفتگو کنیم» | ContactPage |
| رزومه | حفظ | «رزومه صادق وحیدی» | ProfilePage (بررسی در ب۲) |

- **یک H1 در هر صفحه** — دو H1 فعلی رزومه اصلاح می‌شود.
- **canonical برای همه صفحات**؛ **hreflang** فقط بین صفحات رزومه (URL مستقل: fa/en/…)، بر رزومه‌های دوزبانه تک‌URL اعمال نمی‌شود.
- **دوزبانه تک‌URL pages:** با سوییچ درون‌صفحه‌ای می‌مانند (الگوی فعلی؛ تغییر رفتار = ریسک رگرسیون)؛ در sitemap فقط URL اصلی هر صفحه می‌آید.
- **sitemap.xml:** اضافه شدن `about.html`/`projects.html`/`services.html` (+ `magazine.html` پس از اولین مقاله)؛ `robots.txt` بررسی و نگه‌داشتن همه‌آزاد.
- **Core Web Vitals:** preload فونت و lazy-load تصاویر؛ تست موبایل هر فاز با Chrome DevTools (360/390).
- **محتوای مخفی:** بررسی می‌شود بخش چاپی رزومه (CSS مخفی) دوتایی index نشود.

## ۹. مجله (ب۵)

- موقعیت‌دهی: «مجله صادق وحیدی — یادداشت‌های مدیر پروژه و سیستم‌ساز»
- ۶ دسته ثابت (نقد ۳.۳): مدیریت پروژه دیجیتال • طراحی سیستم‌های عملیاتی • مدیریت دانش • اتوماسیون کسب‌وکار • پژوهش بازار • تجربه‌های واقعی
- ساختار کارت مقاله + قالب `/magazine/<post>.html` آماده انتشار
- **قاعدة noindex:** تا وقتی هیچ مقاله‌ای منتشر نشده، `noindex,follow` فعلی می‌ماند؛ با اولین مقاله می‌شود حذف و `magazine.html` به sitemap اضافه می‌شود.
- CTA انتهای مجله ← خدمات/فرم

## ۱۰. قرارداد صداقت محتوا (مهم)

1. **همه متن‌ها واقعی از داده‌های فعلی رزومه** — جعل روایت یا ادعای کاذب ممنوع.
2. **جای‌خالی فقط برای «نتایج کمّی/مدرک بصری»** — با نشانه‌گذاری `[در انتظار آمار]` یا `[در انتظار مدرک]` (جای‌خالی موقتی است، نه ادعای نهایی).
3. **برچسب «اثبات‌شده» فقط جایی که واقعیت قابل استناد هست** (۳۰+ مقاله، ۵+ کتاب، سامانه سبزوار، …).
4. **«نیازمند به‌روزرسانی» حذف** — وضعیت واقعی + تاریخ.
5. **هیچ عددی بدون منبع واقعی روی صفحه زنده نمی‌رود.**

## ۱۱. فازبندی اجرا و وابستگی‌های کاربر

هر فاز = پیاده‌سازی → تست محلی (Chrome DevTools: نوبار/سوییچ زبان/overflow/فرم) → کامیت + push → Pages build → راستی‌آزمایی زنده → گزارش تغییرات.

| فاز | محتوا | وابستگی از کاربر |
|---|---|---|
| **ب۱** | بازنویسی صفحه اصلی FA/EN + وردمارک + برچسب نوبار فارسی + CTA hero | — |
| **ب۳** | services.html + بازطراحی تماس + فرم + Worker + ربات تلگرام | ⚠️ ساخت ربات (BotFather) و Worker — راهنمای قدم‌به‌قدم (~۱۰ دقیقه) |
| **ب۲** | projects.html (۳ سطح + ۵ شاخص) + بازسازی ساختار رزومه fa/en | آمار/تصاویر بعداً در جای‌خالی |
| **ب۴** | about.html + سئوی ساختاری + schema + sitemap/robots | — |
| **ب۵** | بازطراحی مجله + قالب مقاله | اختیاری: ۱–۲ مقاله seed |

لینک‌های نوبار به صفحات جدید تا اتمام فاز مربوطه فعال می‌شوند — هر فاز مستقل و قابل انتشار است. (مثلاً در ب۱ نوبار «درباره» و «پروژه‌ها» روی ۴۰۴ نمی‌روند؛ لینک تا فاز مربوطه مخفی/غیرفعال می‌ماند و وقتی صفحه ساخته شد فعال می‌شود.)
