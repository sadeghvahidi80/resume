خروجی و پشتیبان

برای اعمال دائمی تغییرات در GitHub Pages، خروجی JSON مقالات را بگیرید و در فایل‌های HTML قرار دهید یا به ریپازیتوری commit کنید.

راهنمای اعمال تغییرات

  1. مقالات را در پنل ویرایش/اضافه کنید.
  2. «دانلود JSON مقالات» را بزنید.
  3. فایل JSON را در پوشهٔ پروژه قرار دهید.
  4. با git commit & push تغییرات را به GitHub ارسال کنید.
  5. GitHub Pages به صورت خودکار rebuild می‌شود.
